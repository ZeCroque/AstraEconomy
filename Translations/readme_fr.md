## 1. PRESENTATION

*Vous voulez réduire le grind pour obtenir l'équipement légendaire de vos rêves ? Vous assez simplement besoin de plus d'Astras ? Vous êtes au bon endroit !*

Ce mod ajoute simplement deux entrées de dialogue à Stache dans le QG de l'Alliance des Traqueurs. Le but est de rendre le loot d'équipement légendaire plus gratifiant et de donner une nouvelle utilité aux Astras grâce au système d'amélioration introduit par la mise à jour "Free Lanes".

À l'origine le mod comprenait son propre système de "reroll" d'équipement légendaire qui était moins cheaté (à mon avis) que ceux dans le mods [Legendary Module Recycler](https://www.nexusmods.com/starfield/mods/6074) mod ou la creation de l'équipe de Kinggath [McClarence Outfitters](https://creations.bethesda.net/en/starfield/details/d4f5c6a2-ea4f-4f74-b338-6403c5717ec0/McClarence_Outfitters__Legendary_Customization), car il conservait l'aspect aléatoire. Désormais, il repose sur l'X-Tech et le système vanilla, donc c'est juste une alternative à ces mods, avec une emphase sur les Astras. Il a toutefois l'avantage de vous donner plus d'Astras à dépenser via l'option vanilla de Stache, si c'est ce dont vous aviez besoin.

## 2. DETAILS

### Échange d'équipement légendaire

Stache vous donnera un nombre d'Astra correspondant au "niveau d'étoile" des items que vous lui donnez. Toutes les 3 étoiles, vous obtiendrez un Astra.

Le mod supporte toute sorte de combinaisons, que voici:
- 1x Légendaire 3 étoiles (1 Astra)
- 3x Légendaire 2 étoiles (2 Astras)
- 3x Légendaire 4 étoiles (4 Astra)
- 1x Légendaire 2 étoiles + 1x Légendaire 1 étoile (1 Astra)
- 1x Légendaire 4 étoiles + 1x Légendaire 2 étoiles (2 Astras)
- 1x Légendaire 4 étoiles + 2x Légendaires 1 étoile (1 Astras)

Si le "niveau d'étoile" des items que vous avez donné n'est pas un multiple de 3, le reste vous sera rendu.

### Acheter de l'X-Tech

Le nombre d'X-Tech que vous obtiendrez est redéfinissable dans les options de Gameplay. Voici une liste des réglages disponibles:
- Très cher: Vous obtiendrez 1 X-Tech contre 5 Astras.
- Cher : Vous obtiendrez 1 X-Tech contre 3 Astras.
- Équivalent : Vous obtiendrez 1 X-Tech contre 1 Astra.
- Peu cher : Vous obtiendrez 2 X-Techs contre 1 Astra. [Par défaut]
- Très peu cher : Vous obtiendrez 3 X-Techs contre 1 Astra.

### Langage supportés

Le mod est disponible dans les langages suivants:
- Anglais
- Français
- Allemand (grâce à PearlCanopus)

- *AstraEconomy - Voice_de.ba2*
- *AstraEconomy - Voice_en.ba2*
- *AstraEconomy - Voice_es.ba2*
- *AstraEconomy - Voice_fr.ba2*
- *AstraEconomy - Voice_ja.ba2*

Le mod est marqué comme un "Light file", donc il ne gaspillera pas une précieuse place de votre ordre de chargement.

## 5. INSTALLATION

**Automatique (Recommandé)**
- Utilisez le bouton "Mod Manager Download". Installez et activez le(s) fichier(s) dans votre gestionnaire de mods favori (ModOrganizer2 est ma préférence personnelle).

**Manuelle**
- Extrayez les fichiers requis (cf. `4. CONTENU DU MOD`) depuis l'archive vers votre dossier Data et activez-les dans in-game dans le menu "Creations"
